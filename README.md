Personal portfolio website showcasing my projects, technical skills, and experience in IoT, Embedded Systems, and Full-Stack Development.

## Live Website

🌐 https://samarthravi.com

## About

This portfolio was built to showcase my work in:

- IoT Systems
- ESP32 Development
- Bluetooth Low Energy (BLE)
- Firebase
- React
- TypeScript
- Supabase
- Embedded Systems

The website includes an interactive ASCII hologram, project showcase, GitHub integration, downloadable resume, and a hidden game mode.

## Features

- Responsive modern UI

- Project showcase with GitHub links

## Installation

Clone the repository:

```bash
git clone https://github.com/SamarthRavi/portfolio.git
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
